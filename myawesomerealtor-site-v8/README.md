# MyAwesomeRealtor.com — Site V1

Static, GitHub-Pages-ready real estate website for Steven Lartiga.

## Included
- SEO-focused responsive homepage
- Seller, buyer, landlord/rental, areas-served, Kearny, about, FAQ, contact pages
- Canonical tags, Open Graph, schema markup, robots.txt, sitemap.xml
- Mobile call/text/search bar
- Links to Rosa Agency IDX and MyAwesomeRealtors seller funnel
- CNAME file for myawesomerealtor.com
- 404 page and nojekyll marker

## Before launch
1. Upload the contents of this folder to the intended GitHub Pages repository.
2. Confirm the GitHub Pages custom domain is `myawesomerealtor.com`.
3. Do NOT remove the existing GoDaddy forward until the GitHub Pages deployment is live and tested on its temporary URL.
4. Remove GoDaddy forwarding and point DNS to the hosting provider.
5. Enable/enforce HTTPS after the certificate is issued.
6. Test:
   - https://myawesomerealtor.com
   - https://www.myawesomerealtor.com
   - mobile call/text buttons
   - IDX links
   - seller funnel links
7. Add/verify the new domain in Google Search Console and submit `/sitemap.xml`.
8. Update the real-estate Google Business Profile website field to the new domain after launch.
